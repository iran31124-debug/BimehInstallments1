# مدیریت اقساط بیمه شخص ثالث

نسخه اولیه حرفه‌ای و آفلاین برای ثبت بیمه‌نامه و مدیریت اقساط.

## امکانات
- ثبت نام مشتری، تلفن و پلاک
- ثبت مبلغ کل حق بیمه
- ثبت پیش‌پرداخت
- تعیین تعداد اقساط
- محاسبه خودکار اقساط
- نمایش سررسید اقساط
- ثبت پرداخت هر قسط
- نمایش مانده بدهی
- گزارش مالی کلی
- رابط فارسی و راست‌چین
- ذخیره اطلاعات روی خود گوشی با SQLite

## ساخت APK در GitHub
این پروژه فایل Workflow آماده دارد:
`.github/workflows/build-apk.yml`

پس از قراردادن پروژه در GitHub و اجرای Actions، فایل `app-debug.apk` به عنوان Artifact قابل دریافت است.

## ساخت با Android Studio / AndroidIDE
پروژه را باز کرده و Task زیر را اجرا کنید:
`:app:assembleDebug`

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

> نکته: برای ساخت نسخه انتشار (Release) باید کلید امضای اختصاصی اضافه شود.
