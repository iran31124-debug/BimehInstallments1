# مدیریت حرفه‌ای اقساط بیمه — PRO 2026.3

نسخه پیشرفته برای مدیریت بیمه‌نامه‌های اقساطی:

- ثبت مشتری
- شماره بیمه‌نامه
- پلاک و موبایل
- مبلغ کل و پیش‌پرداخت
- تعداد اقساط
- ساخت خودکار اقساط
- مبلغ هر قسط
- سررسید هر قسط
- تعداد اقساط مانده
- مبلغ بدهی و وصولی
- ثبت پرداخت قسط و پرداخت جزئی
- تشخیص قسط معوق
- پرونده‌ها و جزئیات
- جستجو
- گزارش مالی
- مشتریان
- پشتیبان و اشتراک گزارش
- ذخیره دائمی در SQLite روی گوشی
- رابط فارسی راست‌چین
