# مدیریت حرفه‌ای اقساط بیمه — نسخه 2026.1

این پروژه برای یک اپ واقعی اندرویدی مدیریت اقساط بیمه ثالث طراحی شده است.

## امکانات اصلی
- داشبورد مدیریتی
- ثبت بیمه‌نامه و مشتری
- ذخیره اطلاعات در SQLite روی گوشی
- ساخت خودکار اقساط بر اساس مبلغ و تعداد اقساط
- نمایش سررسید و وضعیت اقساط
- ثبت دریافت و تسویه قسط
- محاسبه فروش، وصولی و مطالبات
- جستجوی مشتری، موبایل، پلاک و شماره بیمه‌نامه
- گزارش مالی و اشتراک‌گذاری
- پشتیبان متنی از اطلاعات
- رابط فارسی راست‌چین و سازگار با تلفن‌های اندرویدی

## ساخت APK در GitHub
فایل workflow در `.github/workflows/build-apk.yml` قرار دارد.
