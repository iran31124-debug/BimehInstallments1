# مدیریت حرفه‌ای اقساط بیمه ثالث - نسخه 2

نسخه جایگزین با رابط فارسی راست‌چین و دکمه‌های واقعی برای:
- ثبت بیمه‌نامه و مشتری
- محاسبه مبلغ اقساط
- نمایش اقساط و وضعیت پرداخت
- ثبت پرداخت و مانده بدهی
- گزارش مالی
- جستجوی مشتری و پلاک
- ذخیره اطلاعات روی خود دستگاه

ساخت APK در GitHub Actions از فایل `.github/workflows/build-apk.yml` انجام می‌شود.
